### Importing Insomnia Collection

1. Open Insomnia preferences
2. Click `Data` -> `Import Data` -> `From File`
3. Select json file

This will create (or update if it already exists) a collection named `Pro API`.  To access this collection click 
`Dashboard` in the top left.


### Exporting Insomnia Collection

1. Open the `Pro API` Collection
2. Open Insomnia preferences
3. Click `Data` -> `Export Data` -> `Export the "Pro API" Collection`
4. Select `Inosmnia v4 (JSON) format`
